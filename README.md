# Budget CLI

Консольное приложение для управления личными финансами.

Написано на TypeScript с использованием библиотеки `inquirer` для интерактивного взаимодействия с пользователем.

## Возможности

- Просмотр списка счетов с балансом и количеством транзакций
- Создание нового счёта с уникальным ID
- Выбор счёта и просмотр его транзакций
- Добавление транзакции с интерактивным вводом и валидацией:
  - выбор типа (доход/расход)
  - выбор категории
  - проверка суммы (положительное число)
  - проверка даты (не в будущем)
  - необязательное описание
- Удаление транзакции с выбором и подтверждением
- Удаление счёта с подтверждением (вместе со всеми транзакциями)
- Экспорт данных счёта в CSV-файл

## Требования

- Node.js версии 16 или выше
- npm

## Установка

```bash
git clone <url-репозитория>
cd budget-cli
npm install
```

## Запуск

### Сборка и запуск скомпилированной версии

```bash
npm run build
npm start
```

### Запуск через ts-node (без предварительной сборки)

```bash
npm run dev
```

## Архитектура

### Классы

- **`Account`** — модель счёта. Хранит список транзакций внутри себя, инкапсулирует логику расчёта баланса и управления транзакциями.
- **`Transaction`** — модель транзакции. Хранит тип, сумму, категорию, описание, дату. Предоставляет вычисляемое свойство `signedAmount` со знаком в зависимости от типа.
- **`AccountManager`** — менеджер счетов. Отвечает за создание, получение, удаление счетов, генерацию уникальных ID.
- **`ApplicationController`** — главный контроллер. Реализует всю логику взаимодействия с пользователем через `inquirer`.

### Интерфейсы

- **`IAccount`** — контракт счёта.
- **`ITransaction`** — контракт транзакции.
- **`IAccountManager`** — контракт менеджера счетов.
- **`ICsvExportResult`** — результат экспорта в CSV.

### Перечисления

- **`TransactionType`** — тип транзакции (`income`, `expense`).
- **`TransactionCategory`** — категории (Зарплата, Еда, Транспорт и т.д.).
- **`MainMenuAction`** — действия главного меню.
- **`AccountAction`** — действия меню счёта.

## Типизация

В проекте включён строгий режим TypeScript (`strict: true`, `noImplicitAny: true`). Явный тип `any` не используется. Для всех переменных, параметров и возвращаемых значений указаны явные типы. Применяются модификаторы `readonly`, `public`, `private`, а также пользовательские типы, интерфейсы и перечисления.

## Валидация

- Название счёта: непустое, не длиннее 50 символов.
- Сумма транзакции: положительное число, поддерживается ввод через запятую или точку.
- Дата: формат `ГГГГ-ММ-ДД`, не в будущем, пустой ввод означает текущую дату.
- Категория и тип выбираются из списка, некорректный ввод исключён.

## Экспорт в CSV

CSV-файлы сохраняются в каталог `exports/` в корне проекта. Имя файла формируется из названия счёта и временной метки. Разделитель полей — `;`. Корректно экранируются значения с запятой, кавычками и переносами строк.

## Пример использования

1. Запустите приложение: `npm start`
2. Выберите «Создать новый счёт», введите название, например «Основной».
3. Выберите счёт в меню, добавьте транзакции (доходы и расходы).
4. Просмотрите список транзакций и баланс.
5. Экспортируйте данные счёта в CSV.
